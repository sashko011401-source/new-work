Python: робота зі списками

Основні команди та мініпроєкт «Список спорядження»

1. Що таке список?

Список у Python — це набір елементів, записаних у квадратних дужках. Елементи можуть бути текстом, числами або іншими значеннями.

things = ["намет", "вода", "їжа"]
print(things)

2. Основні команди роботи зі списками

Створення списку

items = ["вода", "їжа"]

Створює новий список.

Додавання — append()

items.append("ліхтарик")

Додає елемент у кінець.

Видалення — remove()

items.remove("вода")

Видаляє перший відповідний елемент.

Кількість — len()

print(len(items))

Повертає кількість елементів.

Сортування — sort()

items.sort()

Сортує сам список.

Новий відсортований список

new_items = sorted(items)

Створює новий список, не змінюючи початковий.

Перевірка наявності

if "вода" in items:
    print("Є у списку")

Перевіряє, чи є елемент у списку.

Доступ за індексом

print(items[0])
print(items[-1])

Показує перший або останній елемент.

Перебір елементів

for item in items:
    print(item)

Послідовно опрацьовує всі елементи.

3. Мініпроєкт «Список спорядження»

Ця невелика програма допомагає підготувати речі до походу або подорожі. Можна додавати предмети, видаляти їх і перевіряти, чи є потрібна річ у списку.

Поточний список (0 предметів)

    4. Приклад коду Python для мініпроєкту

    things = ["намет", "вода", "їжа", "ліхтарик", "аптечка"]

print("Список спорядження:")
for item in things:
    print("-", item)

new_item = input("Додати предмет: ")
if new_item not in things:
    things.append(new_item)
    print("Предмет додано!")
else:
    print("Такий предмет уже є.")

check_item = input("Що перевірити? ")
if check_item in things:
    print("Цей предмет є у списку.")
else:
    print("Цього предмета немає.")

print("Усього предметів:", len(things))

    Інтерактивний приклад вище працює безпосередньо в браузері. Код у цьому блоці показує, як виконати схожі дії мовою Python.

    5. Перевірка роботи та висновок

    Перевірки:

    • Додати новий предмет — він має з’явитися у списку.
    • Спробувати додати предмет повторно — програма повідомить, що він уже є.
    • Перевірити наявний предмет — програма підтвердить його наявність.
    • Перевірити відсутній предмет — програма повідомить, що його немає.
    • Видалити предмет кнопкою біля нього — список має оновитися.

Мініпроєкт показує, як списки можна використовувати в повсякденному житті для підготовки до подорожі.
